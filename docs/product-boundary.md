# VUA 产品边界

> 状态：已接受
> 范围：VUA 全产品
> 更新：2026-09-01
> 规范效力：有

## 产品定义

VUA 是以 Windows 为首要平台的模块化 VRChat 桌面生产环境，面向希望从素材发现、环境部署一路
完成 Avatar 生产与运行工具配置的玩家。产品采用 Recipe-first、local-first 和可恢复执行原则，
让新用户获得引导路径，同时为熟练用户提供可检查、可复现的生产记录。

## 已接受的模块

1. **Electron 桌面应用**：React、TypeScript、Vite Renderer，隔离的远程网页视图、Session、
   下载交互、桌面窗口和窄化 Gateway；
2. **Rust Orchestrator**：持久任务、计划、批准、恢复、取消、Build Record 与适配器协调；
3. **BDB Local**：内置 BOOTH 浏览与授权下载、本地内容索引、商品/子商品/文件/协议/别名/兼容
   关系，以及 BLM、VAE 等外部来源适配器；
4. **Avatar MegaFactory**：Warehouse、Recipe、Assembly、Production、Inspection、Release 六阶段；
5. **环境部署**：硬件、VR 运行环境、Unity、VRChat 与相关工具的检测和引导式部署；
6. **项目管理**：同时支持 `vrc-get`/ALCOM 和 VCC 的能力感知适配器；
7. **Unity Bridge**：面向 Unity 2022 的版本化、确定性 Editor 操作协议；
8. **桌面与 VR Overlay**：通过稳定应用服务展示引导、状态和运行时工具信息；
9. **运行时工具集成**：以可选托管和外部连接两种模式支持 SlimeVR Server、VRCFaceTracking，
   后续工具沿用同一适配器模型；
10. **第三方插件接口**：版本化协议、能力声明、生命周期、任务、权限与兼容性规则。

## 稳定产品原则

- **Recipe-first**：先选择素材与目标，再创建或修改 Unity 项目；
- **本地优先**：购买会话、订单、下载、付费素材和生产状态保留在用户设备；
- **确定性生产**：可规范化的 Unity 操作通过 Unity Bridge 和 Build Record 复现；
- **能力感知**：官方、开源和社区工具通过适配器并存，界面诚实显示可用能力；
- **可恢复**：长任务具有明确状态、取消、重试、恢复和人工接管路径；
- **最小权限**：远程网页、插件和第三方组件只获得完成任务所需的能力。

## 明确边界

- BDB 不再作为独立云端产品或独立开发仓库；
- VUA 不通过自有服务器代理用户 BOOTH 会话、订单或已购文件；
- VUA 不绕过购买、付费、身份、年龄或访问控制；
- VUA 不分发第三方付费素材，也不把真实付费商品数据作为仓库测试夹具；
- 第三方组件的“可选内置”必须逐项满足许可证、再分发、更新和签名要求；
- 第一阶段不运营托管式插件市场，也不自动运行来源不明的插件；
- VRChat Avatar 的最终上传继续使用官方 SDK 流程，VUA 提供准备、验证和交接；
- 旧仓库的产品边界、计划和 ADR 不自动继承，只有迁移台账批准的资产可以进入新基线。

## 当前阶段

项目处于 pre-alpha 重建期。模块名称和责任已经生效；具体协议只有在新仓库中完成版本化并通过
本地测试后，才具有实现约束力。首次公开发行前还需确定许可证、贡献政策、更新与签名方案。
