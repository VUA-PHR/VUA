# VUA v0.5.0 发行说明


> 日期：2026-09-07
> 类型：M3 门（v0.5.0）：首个 Electron—Orchestrator—Unity 纵向交付
> 基线：v0.4.2

## 概要

M3 门交付首个贯穿 Electron、Rust Orchestrator 与真实 Unity `2022.3.22f1` 的生产纵向
用例：合成 Avatar 加一件衣装，经 `.unitypackage` 直接导入与本地 VPM 制作/安装双素材
入口，完整通过 Inspect 至 Recover 的生命周期矩阵。I-1 真机矩阵 **16/16 格全部在真实
Unity 上通过**（成功、边界取消、源漂移、Bridge 超时、指纹/暂存校验拒绝、回滚失败、
幂等重放）。同门完成六 crate 架构拆分、帧协议握手帧面 Schema 冻结、warehouse 三命令
全链落地，以及三轮用户走查闭环。

## 纵向交付与 I-1 真机矩阵

- 双素材入口跑通：直接导入路径（P1）与本地 VPM 制作/安装路径（P2，暂存模板 + Bridge
  物化 + 确定性发布 + 真实 `vrc-get` 安装 + 目标验证）；
- 16/16 格真机证据（八生命周期 × 双路径）：边界取消（`cancelled` 码+收据）、源漂移
  （首写前 `source_drift`）、Bridge 超时（1s 预算+`Restored`）、陈旧指纹与暂存清单
  篡改触发**真实 C# 校验拒绝**、快照损失注入（`RollbackOutcome::Failed` +
  `rollback_failed` 收据）、重放 351µs 零 Unity；
- 真机证据保留在开发机本地 `_local_w1/`（25 项，16 格全覆盖，含多轮校准 log）；
  集成验收另含证据清单核实与 1 格独立复验；
- 执行纪律：测试永不删除源目录；staging 模板必须种子 SDK（NDMF 编译依赖）——已固化
  在 `material_exec_real.rs` 注释。

## 契约冻结（本门新增）

- **production-use-case v0.1 冻结**（2026-09-07，M3 验收）：四项冻结前置交付核实
  （七方法 Schema、共用固定向量、双端契约测试、I-1 真机矩阵）。2026-09-06 的撤回
  历史保留于协议本状态段（诚实纪律）；
- **amf-production v0.2**（Schema+八向量）随 M3 验收冻结；
- **provider-process v0.2**：握手帧面 Schema 冻结（`provider-frame-v0.1` 双端 11 向量）；
  握手请求 `payload` 必须 `null`，响应必发 `downloadIngest` 能力位（修复 F4-4 位漂移
  根因）。**帧面行为变化**：旧式握手帧将被 `protocol_error` 拒绝；
- **bdl-commands v0.1 → v0.1.1**：warehouse 三命令（setArtifactMode/generateVpm/
  deleteOriginals）词表与协议冻结，含应用面码注记。

## 架构

- **六 crate 拆分落地**：`orchestrator`（核心）、`bdl-store`、`unity-bridge`、
  `provider-host`、`acquisition`、`project-manager`；
- **environment_managers 迁入 `project-manager`**（proposal 004 选项 3）：端口契约
  类型留核心（`VccSettingsReader` 等），wire 面零变化，解析顺序不变式单处归于核心。
