# VUA v0.4.1 发行说明

[English](v0.4.1_EN.md) | [简体中文](v0.4.1_ZH.md)

> 状态：M1 pre-alpha 开发发行版
> 发布日期：2026-09-04
> 产品版本：`0.4.1`

## 本版完成

- Electron Main 在应用就绪时启动进程内受控 Mock Provider，并只通过
  `OrchestratorProviderV01` 版本化表面调用应用核心；
- Desktop Gateway v1 的 `app.snapshot` 先校验来源、大小与信封，再映射到
  `application.getSnapshot`；桌面能力值从 Provider 的操作级 capability 报告派生；
- Main 保持启动、生命周期和路由职责，Provider 的应用语义留在 Provider/Orchestrator 边界；
- 新增真实 Electron 远程权限冒烟：合成 `127.0.0.1` 页面发起 notifications、geolocation 与
  media 请求并被隔离 Session 拒绝；远程页面没有 `window.vua`，不能调用 Gateway；应用窗口的
  远程导航被阻止；HTTP(S) `window.open` 交给 Shell 边界且不创建 Electron 窗口。

## 契约与兼容性

- Desktop Gateway 继续使用 v1，M1 公开面仍只有 `app.snapshot`；
- 应用契约继续使用 `0.1`；本版增加真实消费者，没有改变线格式；
- 当前受控 Provider 是 M1 的进程内测试实现。B2 可以把它替换为受监督独立进程 Provider，而不改
  Renderer 或 Desktop Gateway 调用面。

## 验证与证据

- Workspace TypeScript 检查、单元测试与生产构建通过；
- Electron Main、Preload 与 Renderer 启停冒烟通过；
- 远程权限冒烟命令：`pnpm --filter @vua/desktop smoke:remote-permissions`；
- 本机结构化证据：`_local_m1/v0.4.1/remote-permissions-smoke.json`；
- 本机原始日志：`_local_m1/v0.4.1/remote-permissions-smoke.log`。

`_local_m1/` 由 `.gitignore` 排除。证据与原始日志保留在验收机器，不进入仓库或发行制品。

## 当前限制

- M1 Provider 不承载生产任务；任务入口是否可用完全服从 Provider capability 报告；
- 受监督进程、SQLite 重启恢复和完整任务 Gateway 属于 M2/B2；
- 本版不形成稳定版兼容承诺。
