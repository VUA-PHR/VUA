## 概要

M4 门交付 Warehouse、素材获取与 BDL 全链：catalog 观察管线（服务面＋写入侧＋消费
呈现）、bdl-commands v0.2 全局默认模式、仓储布局重构、设置-实验性完整形态（经用户

修正、proposal 008 仲裁（路径 a）、product-boundary 1.2.0 外部管理项目只读兼容。

  形态取代两级选项（重做批 4fb6411）；

  自动生成（现版本未接线，界面如实标注，生成仍由用户在仓储条目手动发起；导入时

- 形态：标题＋副题＋黄色警示条＋两行开关——「生成 VPM 包替代」全局开关（写

## proposal 008 仲裁（路径 a）

「生成后删除原始素材文件」的协议面经桌面提案、数据/核心两域表态一致后由集成仲裁
**接受路径 a**：开关＝桌面本地偏好；生成任务 Done 回执后由桌面**逐条**调用既有条目级
`warehouse.deleteOriginals`（每条独立审计任务）。零协议扩展，bdl-commands v0.2 维持
冻结；不变式（逐条目删除、独立审计回执、高危确认不弱化）全案约束；接线切片归
M5 首批。路径 b（任务规格旗标升 v0.3）备而不用，路径 c（批量删除命令）拒绝。

## 术语裁定与产品边界

- **术语硬裁定（全仓）**：VPM = VRChat Package Manager（管理器）；VPM 包 = VPM
  package（被管理的包）。受管文档（product-boundary 1.1.1/outline 2.0.6）、应用内
  四语 i18n 与注释已修正；冻结协议文档不追溯（升版时随版修正）；
- **product-boundary 1.2.0（U3 用户裁决）**：对 ALCOM/VCC 管理的项目执行**只读兼容**，
  唯一写路径是用户显式选择的「导入为 VUA 管理的副本」（五项规格）；`1.0.x` 边界内
  写能力一律 false，未来仅经新用户裁决开放；1.2.1 澄清生成触发时机（素材导入时）。
