# VUA Plugins

[Catalog](../README.md)

## Boundary

VUA plugins are separately packaged enhancements that request public versioned capabilities from an
isolated community-plugin host. Individual grants define their complete authority. Kernel authority,
Orchestrator Provider, Electron sessions, application databases, and private types stay with their
owners. Catalog presence records a proposal; security and release review authorize execution.
