## Boundary / 边界

Core entries are repository-owned, reviewed product behavior built directly into VUA. They provide
Orchestrator application capabilities through owned use cases, ports, approval, recovery, and
private-state ownership. They ship as statically reviewed trusted code; the classification creates
no runtime module or registration mechanism.

Core 条目是仓库拥有、经过评审并直接构建进 VUA 的产品行为。它们通过所属用例、端口、批准、恢复
和私有状态所有权提供 Orchestrator 应用能力，并作为静态评审的可信代码随产品发布；该分类不形成
运行时模块或注册机制。
