# Unity 编辑器与路径类配置形态裁决

[English](path-configuration_EN.md) | [简体中文](path-configuration_ZH.md)

> 文档版本：ADR
> 状态：已接受——产品所有者裁决（2026-09-12）
> 范围：Unity 编辑器路径及一切路径类设置项的配置形态（设置面、验证、安全分级、呈现）
> 规范效力：约束环境部署设置面、环境检测呈现、直产链与本地 VPM 生成链的编辑器供给，
> 以及后续一切路径类设置项；与 [Unity Editor 兼容政策](../compatibility/unity-editor_ZH.md)
> 和设计标准衔接
> 裁决背景：工作集群就"Unity 编辑器路径如何在产品中配置"提出三选项（A 立项小配置面 /
> B 维持现状 / C 仅自动探测）；按交互舒适度、效率与安全性评审后采纳组合形态，
> 用户裁决（2026-09-12）并令冻结为文件。

## 裁决

1. **默认零配置**：检测到恰好一个生产目标编辑器（全球版 `2022.3.22f1`）即直接激活，
   设置页仅呈现事实（路径、版本、来源）与「更改」入口；检测到多个候选时按策略选择
   （生产目标版本优先，其次 Unity Hub 默认项），选择过程对用户不可见。**手动选择不是
   标准路径上的必经步骤。**
2. **补救式手选**：检测失败或候选不符生产目标时才出现手动选择，且仅此时出现。
   手动路径必须通过三道验证：
   ① **身份验证**——读取版本串确认确为 Unity 编辑器，不信任路径名；
   ② **版本核验**——精确全球版 `2022.3.22f1` 标「生产目标」；其它版本按
   [兼容政策](../compatibility/unity-editor_ZH.md) 诊断与引导，**绝不静默使用**；
   ③ **信任呈现**——明示"VUA 将以该程序在本机执行生产操作"（批处理即以用户权限
   运行代码），首次实际使用前一次确认，选择记录为用户决定留痕。
3. **配置位置与时机**：路径选择只住在设置页的「环境与路径」节，**不出现在任务中途**；
   任务遇到无编辑器时显示诚实空态 + 一键跳设置，不做中途弹窗选择（中途弹窗会制造
   "先随便选一个"的压力，是错误路径进入生产链的渠道）。
4. **一个配置面喂两条链**：直产链（`.unitypackage` 直接导入）与本地 VPM 生成链共用
   同一编辑器配置；「生成 VPM 替代」实验开关的后端随本配置激活，不做第二处配置。
5. **失败即空态加引导**：检测失败 = 空事实 + 补救入口，永不阻断其它功能。

## 路径类配置通用规则

凡路径类设置项（Unity 编辑器、`vrc-get`、VCC/ALCOM、Steam/SteamVR、下载/暂存目录、
项目目录等）一律适用：

1. **检测优先，事实与来源同显**：每个路径型能力都有探测源；展示探测结果及其来源
   （"来自 Hub 注册表" / "用户手选" / "跟随外部管理器"）；
2. **手选永远带验证**：不提供裸文本框；按工具类型做身份/版本/可写性验证；
3. **失败即空态加引导**：检测失败不是报错，是空事实 + 补救入口；
4. **安全分级**：将被**执行**的路径（编辑器、`vrc-get` 等可执行程序）＝身份 + 版本
   验证 + 首次确认；只被**读写**的路径（下载/暂存/项目目录）＝可写性 + 系统目录防护
   （尤其 Warehouse「删除原始文件」流，误指系统目录即事故）；
5. **按机器存储**：路径设置属本机设置，不进项目、不进 Build Record；诊断脱敏按
   个人信息处理；
6. **一个设置家**：集中在「环境与路径」设置节逐行展示（状态：已探测 / 手选 / 缺失），
   不在各页面散落路径选择器。

## 实施指引与验收

实施切片验收标准：

1. 标准安装零配置激活（检测即事实呈现，来源可见）；
2. 手选三道验证各有拒绝路径（假编辑器 / 错版本 / 用户取消）；
3. 检测失败空态带引导且不阻断其它功能；
4. 直产链与 VPM 生成链读取同一处配置（无第二份拷贝）；
5. 「环境与路径」设置节逐行含来源呈现（已探测 / 手选 / 跟随外部管理器）。

与既有文档的关系：Unity 版本判定与诊断沿用
[Unity Editor 兼容政策](../compatibility/unity-editor_ZH.md)；设置项持久化与呈现纪律沿用
设计标准；**配置激活不等于端到端验证**——W25 真机窗口与门验收的证据要求不因本裁决放宽；
诊断脱敏（M9）实施时按通用规则第 5 条核对。
