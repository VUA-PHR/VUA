# 安全报告 / Security policy

VUA 当前处于 pre-alpha。安全修复优先针对默认分支和最新发布版本；旧版本不承诺单独维护。发现旧版本问题仍欢迎报告，请注明版本或提交。

## 私密报告 / Report privately

请使用 [GitHub 私密漏洞报告](https://github.com/VUA-PHR/VUA/security/advisories/new)。不要通过公开 Issue 披露可利用漏洞或敏感数据。

请提供受影响版本、复现步骤、影响范围和最小合成示例。请勿附上令牌、Cookie、订单、付费素材、完整 Unity 工程、数据库或未清理的日志。维护者会在私密报告中协调修复和披露；目前不承诺固定响应时限。

VUA is pre-alpha. Security fixes target the default branch and latest release; older versions do not have a separate maintenance commitment, but reports about them are welcome.

Use [GitHub private vulnerability reporting](https://github.com/VUA-PHR/VUA/security/advisories/new). Include the affected version, reproduction steps, impact, and a minimal synthetic example. Never attach credentials, cookies, orders, paid assets, complete Unity projects, databases, or unsanitized logs. Maintainers coordinate remediation and disclosure within the private report; no fixed response time is promised.

普通故障、使用问题和建议请使用 [Issues](https://github.com/VUA-PHR/VUA/issues/new/choose)。 / Use Issues for ordinary bugs, questions, and suggestions.
