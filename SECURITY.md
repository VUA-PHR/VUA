# Security policy

VUA is in continuing Beta with no scheduled v1.0.0. Security fixes target the default branch and
latest release. Older versions do not have a separate maintenance commitment, but reports about
them are welcome; include the affected version or commit.

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/VUA-Project/VUA/security/advisories/new).
Do not disclose exploitable vulnerabilities or sensitive data in public Issues.

Include the affected version, reproduction steps, impact and a minimal synthetic example. Do not
attach credentials, tokens, cookies, orders, paid assets, complete Unity projects, databases or
unsanitized logs. Maintainers coordinate remediation and disclosure within the private report;
no fixed response time is promised.

Use [Issues](https://github.com/VUA-Project/VUA/issues/new/choose) for ordinary bugs, usage questions
and suggestions.
